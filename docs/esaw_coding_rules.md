# ESAW接触方式：本研究的复用规则

版本：2026-11-10；本轮固定103起，不改变中国研究主类、49起重点组或原因统计。

## 分析单位

本表是对103份报告逐案形成的接触方式摘要。ESAW原方法以受伤者为记录对象；事故摘要不是103名受害者，也不是已完成全部伤者的ESAW报送。多人事故在同等最重伤者接触不同、或资料无法排序时，事故级使用00，并在补充表保留已知分组。补充表只收录六组已明确描述的受害者，不是完整受害者名册。

## 判定顺序

1. 先读经过和伤害结果，再核对原因、尸检或诊疗说明。
2. 分开记录任务、异常、接触、结果，不由事故名称或中国研究主类自动换码。
3. 同一人出现多个接触时，采用报告支持的最严重伤害对应接触；时间最后发生不自动等于最严重。
4. 原文能细分时用细码，只能识别接触组时使用组级码。00表示资料不足或事故级不唯一，不等于没有伤害；99也不用于代替未知。
5. 主接触不同的同等严重者，不按人数多数投票掩盖少数受害者的接触。
6. 每案保留判断理由、来源、章节、定位、替代码和分析单位说明。扫描件局部转录与完整文字提取分开记录；官方补充来源单列。

本研究将事故摘要无法唯一表达的情况也以00作占位，并用non_unique_kind区别于信息缺失。这是事故级适配规则，不是宣称ESAW原方法要求把已知但不同的受伤者接触合并为00；L40在受害者分组中实际有62与41两种已知码。

## 本轮容易混淆的情形

- M17：落料先砸垮平台，死亡者随后坠落；主接触摘要为31。此前中国主类仍按其独立规则记录。
- N24：缺氧晕厥在先，报告明确严重烫伤后死亡；接触为13。
- L17：中毒、缺氧之后在污水中溺死；接触为21。
- M30：钢筋棒先被辊轮卷入、窜出后击中另一人；接触为41，不是受害者卷入机器。
- M05：皮带带人后头部撞托辊，但托辊运动状态未说明，保留00及32/44候选。
- L40：同案两名死者被墙体压住，一名死者被飞散物击中，事故级00，分组表记录62和41。

## 使用结果

逐案记录共103条：85条细码、5条组级码、13条00。13条00继续保留在103分母中；如描述可判定接触的内部构成，则分母为90，并明确排除了哪些记录。这个口径不用于替换既有103起的中国事故主类比例。

## 来源与性质

采用Eurostat 2013稳定版本第5.2.6节及附录接触指南。中文标签为本研究释义，不是官方中文标准，也不把ESAW称作ISO。ISO 12100可用于机械风险评估；ISIC用于经济活动；二者均不取代接触编码。代码和规则由AI辅助对原始叙述作研究判断，没有声称双人独立编码或专家认证。
